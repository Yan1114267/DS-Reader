# 🐳 大鲸鱼阅读 · Whale Tutor

上传 **PDF / PPTX / DOCX / SVG / TXT / MD**，让 AI 用「英文为主 + 中文翻译」为你讲课。

- 🔵 **学术术语自动标注**：术语在正文中显示为蓝色下划线（DeepSeek 蓝），鼠标悬停弹出中文译名与中英双语释义。
- 🧭 **点击跳回定义**：同一术语在后文再次出现时，左键点击即可平滑跳转到它首次定义的位置，并有高亮闪烁提示；右上角还能「回到刚才的位置」。
- 🌏 **中英对照**：英文讲解为主体，每一段英文下方紧跟中文翻译；标题、小节标题也是双语。
- 📚 **自动术语表**：课程末尾生成术语卡片，点击也能跳转到定义。
- 🎛️ **生成前定制格式**：右侧底部的「课程要求」输入栏，可以告诉 AI 用表格对比、分点讲解、标出考试重点或出题；也有快捷模板可点选。
- 🖼️ **SVG / 图片文字**：SVG 文件以及 PPT / DOCX 里嵌入的 SVG 会直接读取文字；PPT 图片、扫描版 PDF 可以通过支持视觉的模型做 OCR。
- 💬 **随时答疑**：右上角打开「问大鲸鱼」，基于当前讲义与原始资料回答；支持中文 / 双语切换、流式输出和随时停止，也会记得本会话的追问上下文。
- 🔑 **自带 API Key**：兼容 OpenAI Chat Completions 协议，直接填 Base URL / 模型 / Key 即可使用。
- 🎛️ **模型自动识别**：填好 Base URL 和 API Key 后，点「识别模型」即可读取服务商的 `/models` 列表；点一下「模型名称」输入框会展开模型菜单，可输入关键字过滤、用 ↑/↓ 与回车选择，也仍然支持手动填写任意模型名。
- 🐳 **演示模式**：没有 API Key 也能打开一节示例课，体验全部标注与跳转效果。

## 快速开始

1. 双击 `index.html`（推荐用 Edge 或 Chrome 打开）。
2. 在左侧填写：
   - **接口地址 Base URL**
   - **API Key**
   - **模型名称**：填好前两项后点「识别模型」，会自动列出这个 Key 可用的模型；点一下输入框会展开模型菜单，选中即可，也可以直接手填。
3. 如果资料里有图片文字（PPT 截图、扫描版 PDF），先勾选「识别图片里的文字」，并填一个**支持视觉的模型名称**（留空则沿用上方模型；共用同一个 Base URL 和 Key），再上传资料。
4. 上传一份资料，等解析完成。
5. 在右侧底部的「课程要求」输入栏里写下你想要的格式（可选，也可以点「分点讲解 / 表格对比 / 考试重点」等快捷模板），然后点「开始上课」。生成后按钮会变成「重新备课」，修改要求后可再次生成。
6. 阅读时点右上角的「💬 问大鲸鱼」，随时提问；小窗右上角可切换 **中文 / 双语** 回答。
7. 想先看效果？点击欢迎页的「先看一节演示课」，无需 API Key。

### 常用服务商配置

| 服务商 | Base URL | 模型示例 | 备注 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 中国大陆访问较方便 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | 需可访问 OpenAI |

只要服务商兼容 OpenAI 的 `/chat/completions` 接口，都可以填进来；也可以直接填完整的 `.../chat/completions` 地址。

## 功能细节

- 文本与结构解析在浏览器本地完成：
  - PDF 使用 pdf.js
  - DOCX 使用 mammoth.js
  - PPTX 使用 JSZip 读取幻灯片 XML
  - SVG 直接解析 XML 里的文字
- PPTX / DOCX 里嵌入的 SVG 图片文字、图片 `alt` 说明会一并读取；SVG 是矢量文字，不需要 OCR。
- 只有勾选「识别图片里的文字」后，PPT 图片和扫描版 PDF 才会被缩放并发送给视觉模型做 OCR；图片不会在本地做 OCR。
- OCR 限制：每个文件最多识别 20 张图片；扫描 PDF 最多识别 12 页；只对几乎没有文字层的 PDF 页面做 OCR。识别结果受模型能力和图片清晰度影响。
- 文档会按约 **9000 字符** 切段，逐段请求模型生成结构化 JSON（标题、小节、英文段落、中文翻译、术语定义），再合并渲染。
- 「课程要求」会在第一次生成前追加到系统提示词中；它可以在保持 JSON 结构、双语字段和术语规则的前提下，改变分节、篇幅、重点、表格、练习等呈现方式。
- 课程正文支持轻量 Markdown：**加粗**、*斜体*、行内代码、项目符号、编号列表、Markdown 表格、小标题、引用和代码块；术语在表格和列表中也会正常标注、悬停和跳转。
- 课程要求会保存在本机浏览器（`localStorage`），清空或修改后重新生成即可生效。
- 术语识别与锚点由前端完成：AI 返回术语表后，程序在正文中自动查找所有出现位置，首个出现处作为定义锚点，其余位置生成可点击的跳转链接。
- 答疑会携带当前课程讲义、术语表、原始资料节选（默认最多约 6000 字符）以及本会话最近几轮问答；不依赖后端，也不会把内容发到别处。
- 答疑默认使用流式输出；如果服务商不支持流式返回，会自动回退为普通响应。
- 生成新课程时会自动清空旧答疑记录，避免上一份资料的上下文干扰新课程。
- 动画、悬停提示、术语表、回到原位置等都是纯前端实现，无需后端。

## 常见问题

**Q：点「识别模型」失败或没有下拉选项？**
识别模型调用的是 OpenAI 兼容的 `GET /models` 接口。部分服务商不提供该接口，或不允许浏览器跨域访问（CORS）；这种情况下直接手动填写模型名称即可，不影响正常备课。本地 Ollama 需要先 `ollama pull` 模型，Key 可以留空。

**Q：用 deepseek-flash 时提示「第 1 段返回的内容不是有效 JSON」？**
DeepSeek V4 / Flash 默认开启思考模式，思考产生的 `reasoning_content` 会占用 `max_tokens`。本项目每段要输出较长的中英双语 JSON，原来的 4096 token 很容易被思考过程吃掉，`finish_reason` 变成 `length`，JSON 就被截断；JSON 模式下服务商还可能把不完整的 JSON 替换成空格，所以前端会报“不是有效 JSON”。新版已为 DeepSeek 请求自动关闭思考模式，并把每段 `maxTokens` 提到 8192；若服务商不支持 `thinking` 参数，会自动退回兼容请求。

另外，本项目不会把 PDF 原文件直接上传给模型：它先在浏览器里用 pdf.js 提取文字，再按段调用 `/chat/completions`。DeepSeek 网页端“支持 PDF”走的是 Files API（先上传文件，再在对话里引用 `file_id`），和这里纯前端调用不是同一条路径；所以“模型支持 PDF”并不代表它一定能顺利处理本项目的长文本 JSON 任务。

**Q：双击打开后，调用接口报「网络请求失败 / CORS」？**
浏览器直连 API 时，服务商必须允许跨域（CORS）。如果服务商不支持，可更换服务商，或使用本地 Ollama。另外也可以在项目文件夹运行：

```bash
python -m http.server 8080
```

再打开 `http://localhost:8080`。注意：本地静态服务器不能绕过服务商自身的 CORS 限制。

**Q：答疑用中文还是英文回答？**
聊天小窗右上角可切换「中文 / 双语」。中文模式用中文讲解并保留英文术语；双语模式为英文主体、逐段附中文翻译。语言选择会保存在本机浏览器。

**Q：答疑会读到哪些内容？**
会带上当前课程的讲义、术语表、原始资料的节选（默认最多约 6000 字符）以及本会话最近几轮问答。更换资料并重新生成课程后，旧聊天会自动清空。

**Q：答疑记录会被保存吗？**
聊天记录只存在当前页面里，刷新页面或生成新课程后清空，不会写入本地存储。

**Q：怎样让 AI 用表格、分点或出题？**
在右侧底部的「课程要求」输入栏里写清楚，或点「分点讲解 / 表格对比 / 考试重点 / 逐句双语 / 先总后分」快捷模板，再点「开始上课」。课程生成后想调整，修改要求再点「重新备课」即可。主体语言仍保持英文 + 中文翻译，格式要求主要控制结构、重点、表格和练习。

**Q：课程要求会保存吗？**
会保存在本机浏览器；点「清空要求」可以移除。它只影响课程生成，不影响右上角答疑（答疑有自己的中文 / 双语开关）。

**Q：PPT 图片里的文字怎么读？**
在「上传学习资料」里勾选「识别图片里的文字」，填一个**支持视觉的模型名称**（例如 `gpt-4o-mini`、Qwen-VL 系列、GLM-4V 系列，具体以服务商控制台为准），再重新上传文件。它会和上方共用 Base URL 与 Key。

注意：
- 当前 DeepSeek 的文本模型 `deepseek-chat` 不识别图片；需要换成支持视觉的模型或服务商。
- 设置后要重新选择文件才生效；每个文件默认最多识别 20 张图片。
- 如果模型不支持图片，会显示识别警告，但普通文字仍会正常提取。

**Q：扫描版 PDF 上传后没有内容？**
先勾选「识别图片里的文字」并配置视觉模型，再重新上传。扫描页会被渲染成图片后识别，默认最多处理 12 页；没有勾选或模型不支持图片时，就会提示没有可读文字。

**Q：SVG 里的文字读不出来？**
只有当 SVG 里是真正的 `<text>` 文字节点时才能本地提取；如果文字已经被转成路径或一张位图，请截图并使用图片文字识别。

**Q：支持旧版 `.doc` / `.ppt` 吗？**
不支持，请先用 Office / WPS 另存为 `.docx` / `.pptx`。

**Q：文档太长，只讲了一部分？**
默认最多处理 8 段、约 7.2 万字符。可以打开 `app.js`，修改顶部的 `CONFIG.chunkSize` 和 `CONFIG.maxChunks`。

**Q：术语太多 / 太少 / 不准？**
术语由模型根据提示词挑选。可以修改 `app.js` 顶部的 `SYSTEM_PROMPT`，调整术语数量上限和筛选标准。

**Q：API Key 安全吗？**
- 默认不会保存密钥；只有勾选「在这台电脑上记住密钥」后，才会存进浏览器 `localStorage`。
- 所有请求由浏览器直接发送到你填写的服务商；本项目没有后端，也不会把文件或密钥发往别处。
- 文件内容与答疑问题会作为提示词发送给你选择的 AI 服务商，请注意资料本身的保密要求。
- 启用图片识别时，PPT / PDF 中的图片也会发送给同一个服务商做 OCR；未勾选时不会发送图片。

**Q：需要联网吗？**
只有调用 AI 时需要联网。PDF / DOCX / PPTX 解析库已经随项目附带在 `vendor/` 目录，文本解析和演示模式都可以离线使用；如果开启了图片文字识别，还需要能访问你配置的视觉模型接口。

## 项目结构

```
whale-tutor/
├── index.html   # 页面结构
├── styles.css   # 界面样式
├── app.js       # 文件解析、课程要求、Markdown 渲染、术语标注、跳转与答疑
├── vendor/      # 随项目附带的解析库
│   ├── pdf.min.js
│   ├── pdf.worker.min.js
│   ├── mammoth.browser.min.js
│   └── jszip.min.js
└── README.md
```

解析库许可：pdf.js（Apache-2.0）、mammoth.js（BSD-2-Clause）、JSZip（MIT / GPLv3 双许可）。

## 可自定义的地方（app.js 顶部）

```js
const CONFIG = {
  chunkSize: 9000,   // 每次送给模型的材料字符数
  maxChunks: 8,      // 单次备课最多生成几段
  maxTokens: 8192,   // 每段回答的最大 token 数（思考模式会占用输出额度）
  temperature: 0.4
};
```
